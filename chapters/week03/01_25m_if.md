# Week 3 制御構文（if で分岐する）

テーマは制御構文です。今日は if 文で処理を分けます。Week 1 で読んだ if を、今回は自分で書きます。

## まず押さえること

if 文は、条件によって動く処理を変えます。条件は true か false になる式です。Week 1 で見た `>=` や `==` を使います。

```
if (条件1) {
    // 条件1 が true のとき動く
} else if (条件2) {
    // 条件1 が false で、条件2 が true のとき動く
} else {
    // どれも false のとき動く
}
```

上から順に条件を調べます。最初に true となった枝だけが動きます。1つ動いたら、残りの枝は調べません。`else` はどれも当てはまらないときの受け皿です。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。1行写すごとに「この行は何をするか」を予測してから写します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week03/01_25m_if/Grade.java` にします。

```java
public class Grade {
    public static void main(String[] args) {
        int score = 75;
        if (score >= 80) {
            System.out.println("A");
        } else if (score >= 60) {
            System.out.println("B");
        } else {
            System.out.println("C");
        }
    }
}
```

実行は `java src/main/java/com/example/week03/01_25m_if/Grade.java` です。予測: score は 75。どの枝が動くでしょうか。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Grade` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `Grade`
- `int score` … 75 を入れる
- `score >= 80` なら `A` を表示する
- そうでなく `score >= 60` なら `B` を表示する
- どちらでもなければ `C` を表示する

## ステップ3: 自力

新しいファイル `src/main/java/com/example/week03/01_25m_if/Sign.java` を作ります。これまでのファイルは直しません。

テーマは「数の符号を判定する」です。次のとおり書いてください。

- 数 … 整数の変数を1つ作る。値は自由（例 -4）
- その数が 0 より大きければ `正` と表示する
- 0 と等しければ `ゼロ` と表示する
- どちらでもなければ（0 より小さければ）`負` と表示する

if・else if・else の3つの枝で書きます。クラス名は `Sign` にします。書けたら回答を `submissions/week03/01_25m_if.md` に貼り、「レビューして」と言ってください。

今回のポイントは、3つの枝を上から順に組み立てることです。まず 0 より大きいか、次に 0 と等しいか、最後に else、という順で考えてください。
