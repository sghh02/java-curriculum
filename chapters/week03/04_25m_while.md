# Week 3 制御構文（while でくり返す）

テーマは制御構文の続きです。今日は while 文です。もう1つのくり返しの書き方を覚えます。

## まず押さえること

while 文は、条件が true の間ずっとくり返します。for が「決まった回数」なのに対し、while は「条件が続く間」です。回数が前もって分からないときに向いています。

```
while (条件) {
    // 条件が true の間、ここがくり返し動く
}
```

大事な注意が1つあります。くり返しの中で、条件に関わる値を必ず変えてください。変えないと条件がずっと true のままで、永遠に止まりません。これを無限ループと呼びます。

```
int n = 5;
while (n > 0) {
    System.out.println(n);
    n = n - 1;   // これがないと n はずっと 5 のまま。止まらない
}
```

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が、どの順で表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week03/04_25m_while/Countdown.java` にします。

```java
public class Countdown {
    public static void main(String[] args) {
        int n = 5;
        while (n > 0) {
            System.out.println(n);
            n = n - 1;
        }
        System.out.println("発射");
    }
}
```

実行は `java src/main/java/com/example/week03/04_25m_while/Countdown.java` です。

- くり返しの中で、n を1行表示してから `n = n - 1;` で1減らす
- くり返しが終わったら `発射` を表示する
