# Week 3 制御構文（for でくり返す）

テーマは制御構文の続きです。今日は for 文で、同じ処理をくり返します。

## まず押さえること

for 文は、決まった回数だけ処理をくり返します。書き方はこうです。

```
for (int i = 1; i <= 5; i++) {
    // ここが毎回くり返し動く
}
```

丸かっこの中は、セミコロンで3つに分かれています。

- `int i = 1` … 最初に1回だけ。回数を数える変数 i を用意する。
- `i <= 5` … 毎回のはじめに調べる条件。true の間はくり返す。
- `i++` … 毎回の終わりに動く。`i = i + 1` の短い書き方。i を1増やす。

i が 1 から始まり、5 以下の間くり返し、毎回1ずつ増えます。i が 6 になると条件が false になり、くり返しが終わります。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何回くり返すか」「何が表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week03/02_25m_for/Numbers.java` にします。

```java
public class Numbers {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}
```

実行は `java src/main/java/com/example/week03/02_25m_for/Numbers.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Numbers` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `Numbers`
- for … i を 1 から 5 まで、1ずつ増やしながら回す
- くり返しの中で、i を1行ずつ表示する
