# Week 3 三項演算子（1行で書く条件分岐）

前回は switch で枝分かれしました。今回は `if` を1行に縮める書き方です。三項演算子と呼びます。「条件で値を選ぶだけ」の場面で使います。

自分で書かなくても、読む機会は多い書き方です。現場のコードでは表示の切り替えでよく出てきます。

## まず押さえること

`if` で値を選ぶだけの処理を思い出してください。

```
String result;
if (score >= 60) {
    result = "合格";
} else {
    result = "不合格";
}
```

同じことを1行で書けます。

```
String result = score >= 60 ? "合格" : "不合格";
```

読み方はこうです。はてなの前が条件です。はてなの後ろが、条件を満たしたときの値です。コロンの後ろが、満たさなかったときの値です。

値を選ぶだけの場面で使います。処理を何行も書きたいときは `if` のままにしてください。無理に縮めると読みにくくなります。

`+` と組み合わせるときは、丸かっこで囲みます。囲まないと、つなぐほうが先に働きます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week03/08_30m_三項演算子/TernaryDemo.java` です。

```java
public class TernaryDemo {
    public static void main(String[] args) {
        int score = 72;
        String result = score >= 60 ? "合格" : "不合格";
        System.out.println("判定: " + result);

        int a = 15;
        int b = 9;
        int max = a > b ? a : b;
        System.out.println("大きいほう: " + max);

        int count = 0;
        System.out.println("件数: " + (count == 0 ? "なし" : count + "件"));
    }
}
```

実行は `java src/main/java/com/example/week03/08_30m_三項演算子/TernaryDemo.java` です。

写しながら、次を自分に問いかけてください。

- `score` が 60 ちょうどのとき、どちらが選ばれるか
- `max` に入るのは a と b のどちらか
- 3つめの行で丸かっこを外すと何が起きるか
- 三項演算子が返しているのは処理と値のどちらか
