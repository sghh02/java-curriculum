# Week 3 制御構文（for と if を組み合わせる）

テーマは制御構文の総合です。for の中に if を入れて、くり返しながら条件で分けます。

## まず押さえること

for でくり返す1回ごとに、if で「この回は処理するか」を決められます。for の `{ }` の中に if を書くだけです。

```
for (int i = 1; i <= 10; i++) {
    if (条件) {
        // 条件が true の回だけ動く
    }
}
```

割り切れるかの判定には `%` を使います。`i % 2` は i を 2 で割ったあまりです。あまりが 0 なら、2 で割り切れる、つまり偶数です。

```
i % 2 == 0   // i は偶数
i % 3 == 0   // i は 3 の倍数
```

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week03/03_25m_forとifの組み合わせ/Even.java` にします。

```java
public class Even {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                System.out.println(i);
            }
        }
    }
}
```

実行は `java src/main/java/com/example/week03/03_25m_forとifの組み合わせ/Even.java` です。1 から 10 のうち、何が出るでしょうか。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Even` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `Even`
