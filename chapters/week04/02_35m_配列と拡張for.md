# Week 4 配列と拡張for（一覧をまとめて扱う）

Week 4 の続きです。前回はメソッドで、処理に名前を付けました。今回は配列を扱います。値を1つずつ別の変数に入れるのではなく、同じ型の値をまとめて1つの入れ物へ入れます。

題材は在庫管理です。商品名と在庫数を配列で持ち、全件を表示して合計を出します。REST API では「一覧を配列やリストで受け取り、まわして処理する」場面が絶えず出てきます。その最小形をここで身につけます。

## まず押さえること

配列は、同じ型の値をまとめて入れる箱です。`String[]` と書くと、String をいくつも入れられる箱になります。

```
String[] names = {"りんご", "みかん", "ぶどう"};   // 3つ入りの箱を作る
System.out.println(names[0]);                     // りんご。番号は 0 から始まる
System.out.println(names.length);                 // 3。中身の個数
```

番号は 0 から始まります。3つ入っていれば、使える番号は 0、1、2 です。個数は `.length` で分かります。メソッドではないので、カッコは付きません。

まわし方は2つあります。通常for と拡張for です。

```
for (int i = 0; i < names.length; i++) {   // 番号を使う。i で位置が分かる
    System.out.println(names[i]);
}

for (String n : names) {                   // 番号を使わない。中身だけ取り出す
    System.out.println(n);
}
```

使い分けはこうです。番号が要るときは通常forを選びます。2つの配列を同じ位置で組み合わせたいときも通常forです。中身だけ順に見ればよいときは拡張forを選びます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week04/02_35m_配列と拡張for/StockArrayDemo.java` です。

```java
public class StockArrayDemo {
    public static void main(String[] args) {
        String[] names = {"りんご", "みかん", "ぶどう"};
        int[] stocks = {12, 30, 8};

        for (int i = 0; i < names.length; i++) {
            System.out.println(names[i] + ": " + stocks[i] + "個");
        }

        int total = 0;
        for (int stock : stocks) {
            total += stock;
        }
        System.out.println("合計在庫: " + total + "個");
    }
}
```

実行は `java src/main/java/com/example/week04/02_35m_配列と拡張for/StockArrayDemo.java` です。

- `names.length` はいくつになるか
- 通常for と拡張for は、それぞれ何が違うか
- `total += stock` は何回動き、最後に total はいくつになるか
