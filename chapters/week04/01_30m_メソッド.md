# Week 4 メソッド（処理に名前を付ける）

テーマはメソッドです。今日は処理をひとまとめにして名前を付け、それを呼び出します。同じ処理を何度も使えるようになります。

## まず押さえること

メソッドは、処理のかたまりに名前を付けたものです。`main` もメソッドの1つです。自分で新しいメソッドを作れます。

メソッドには、値を渡せます。これを引数と呼びます。メソッドは、結果を返せます。これを戻り値と呼びます。

```
戻り値の型 メソッド名(引数の型 引数名) {
    // 処理
    return 戻り値;
}
```

呼び出すときはメソッド名を書きます。`makeGreeting("太郎")` のように、かっこの中に渡す値を書きます。

なお `static` は、今のところおまじないとして付けてください。`main` から直接呼ぶメソッドに必要です。意味は Phase 2 で扱います。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が、どの順で表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week04/01_30m_メソッド/Greeter.java` にします。

```java
public class Greeter {
    public static void main(String[] args) {
        String message = makeGreeting("太郎");
        System.out.println(message);
        System.out.println(makeGreeting("花子"));
    }

    static String makeGreeting(String name) {
        return "こんにちは、" + name + "さん";
    }
}
```

実行は `java src/main/java/com/example/week04/01_30m_メソッド/Greeter.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Greeter` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- `makeGreeting(String name)` … `static` を付ける。`こんにちは、◯さん` の形の文字列を返す
- main の流れ
  - `makeGreeting("太郎")` の結果を変数へ入れ、表示する
  - `makeGreeting("花子")` の結果を、そのまま表示する

## ステップ3: 自力

新しいファイル `src/main/java/com/example/week04/01_30m_メソッド/Calculator.java` を作ります。これまでのファイルは直しません。

テーマは「2つの数の合計を返す」です。次のとおり書いてください。

- `add` というメソッドを作る。int を2つ受け取り、合計を int で返す
- `main` の中で `add(3, 5)` を呼び、その結果を変数に入れて表示する
- 続けて `add(10, 20)` の結果も表示する

クラス名は `Calculator` にします。書けたら回答を `submissions/week04/01_30m_メソッド.md` に貼り、「レビューして」と言ってください。

今回のポイントは2つです。引数で値を受け取ること。`return` で結果を返すこと。戻り値は変数に入れても、そのまま表示しても構いません。

（予測: `add(3, 5)` と `add(10, 20)` は、それぞれ何を返すでしょうか。）
