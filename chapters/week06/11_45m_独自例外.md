# Week 6 独自例外（自分で例外の種類を作る）

Week 4 で例外を受け止める書き方を学びました。今回は例外そのものを自分で作ります。継承を使います。

現場では業務のエラーごとに例外を作ります。在庫が足りない、期限が切れている、といった種類です。名前を見ただけで何が起きたか分かるのが利点です。Spring では、この独自例外を受け取って画面のエラー表示へつなぎます。

## まず押さえること

例外もクラスです。作るには継承します。

```
class StockShortageException extends Exception {
    StockShortageException(String message) {
        super(message);
    }
}
```

`super(message)` は親のコンストラクタを呼ぶ書き方です。渡した文字列は `getMessage()` で取り出せます。

ここでの引数名 `message` は自分で自由に決めてよいものです。呼び出し元とは無関係で、`msg` でも構いません。

親に何を選ぶかで性質が変わります。

- `Exception` を継承 … 検査例外。呼び出し側に `catch` か `throws` を強制する
- `RuntimeException` を継承 … 非検査例外。強制しない

呼び出し側に必ず対応させたいなら `Exception` です。今回はこちらを使います。

投げるときは `throw` を書きます。投げる可能性のあるメソッドには `throws` を書きます。

```
static void buy(int stock) throws StockShortageException {
    throw new StockShortageException("足りません");
}
```

名前は `Exception` で終わらせる決まりがあります。文法ではなく約束です。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week06/11_45m_独自例外/CustomExDemo.java` です。

```java
public class CustomExDemo {
    public static void main(String[] args) {
        try {
            buy(10, 3);
        } catch (StockShortageException e) {
            System.out.println("エラー: " + e.getMessage());
        }

        try {
            buy(2, 5);
        } catch (StockShortageException e) {
            System.out.println("エラー: " + e.getMessage());
        }
    }

    static void buy(int stock, int order) throws StockShortageException {
        if (stock < order) {
            throw new StockShortageException("在庫が足りません。残り " + stock + " 個");
        }
        System.out.println("購入できました");
    }
}

class StockShortageException extends Exception {
    StockShortageException(String message) {
        super(message);
    }
}
```

実行は `java src/main/java/com/example/week06/11_45m_独自例外/CustomExDemo.java` です。

写しながら、次を自分に問いかけてください。

- 1つめの `buy(10, 3)` は例外を投げるか
- `throw` のあとの `System.out.println` は動くか
- `buy` から `throws` を消すとどうなるか
- `e.getMessage()` が返す文字列はどこで決まったか
