# Week 6 enum（決まった値だけを持つ型）

前回は `final` で値を固定しました。今回は種類そのものを固定する道具です。列挙型と呼びます。`enum` と書きます。

状態や区分を表すのに使います。受付中と終了、有効と無効のような値です。DB の区分カラムと相性がよく、現場では必ず出てきます。文字列で扱うと打ち間違いが起きますが、`enum` なら書き間違えた時点でコンパイルエラーになります。

## まず押さえること

宣言はクラスに似ています。値を並べて書きます。

```
enum Status {
    ACTIVE, CLOSED
}
```

これで `Status` という型ができます。入る値は 2 つだけです。ほかの値は入りません。

使うときはクラス名から書きます。

```
Status s = Status.ACTIVE;
```

便利な道具が最初から付いています。

- `values()` … 全部の値を順番に取り出す
- `ordinal()` … 並び順の番号を返す。先頭が 0
- `name()` … 名前を文字列で返す

`switch` に渡すと読みやすくなります。`enum` の値なら、`case` に型名を書かずに済みます。

```
String s = switch (値) {
    case ACTIVE -> "受付中";
    case CLOSED -> "終了";
};
```

すべての値を書けば `default` は要りません。値が増えたときにコンパイラが教えてくれます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week06/10_45m_列挙型/EnumDemo.java` です。

```java
public class EnumDemo {
    public static void main(String[] args) {
        Status s = Status.ACTIVE;
        System.out.println("状態: " + s);
        System.out.println("並び順: " + s.ordinal());

        for (Status one : Status.values()) {
            System.out.println("一覧: " + one);
        }

        Status other = Status.CLOSED;
        String message = switch (other) {
            case ACTIVE -> "受付中";
            case CLOSED -> "終了";
        };
        System.out.println("説明: " + message);
    }
}

enum Status {
    ACTIVE, CLOSED
}
```

実行は `java src/main/java/com/example/week06/10_45m_列挙型/EnumDemo.java` です。

写しながら、次を自分に問いかけてください。

- `s` をそのまま表示すると何が出るか
- `ACTIVE` の `ordinal()` はいくつか
- `values()` は何個の値を返すか
- `switch` に `default` がないのはなぜか
