# Week 6 ポリモーフィズム（親型でまとめ、子ごとに動きを変える）

Week 6 の総仕上げです。継承・オーバーライド・抽象クラスをつなげます。ポリモーフィズム（多態性）は「親の型でまとめて持ち、同じ呼び出しをすると、中身の子ごとに違う動きをする」ことです。在庫でいえば、`商品` という親型の配列に生鮮と乾物をまとめて入れておき、同じ `label()` を呼ぶだけで「要冷蔵」「常温保存」と別々に返ります。Spring Boot でも「親型のリストでまとめて扱う」場面は絶えず出てきます。

## まず押さえること

ポイントは、配列やリストの型を親にすることです。中身には子を入れます。同じメソッドを呼ぶと、実体の子ごとにオーバーライドした中身が動きます。呼ぶ側は子の種類を意識しなくてよくなります。

```
abstract class Goods {
    abstract String label();          // 中身なし。子が実装する
}

class FreshGoods extends Goods {
    String label() { return "要冷蔵"; }   // 子ごとに違う中身
}

Goods[] shelf = { new FreshGoods(), new DryGoods() };  // 型は親、中身は子
for (Goods g : shelf) {
    g.label();     // 同じ呼び出しでも、中身の子ごとに結果が変わる
}
```

抽象クラスは前回どおりです。`abstract` で中身のないメソッドを親へ置き、子が実装します。今回はそれを「親型の配列にまとめて、ループで同じメソッドを呼ぶ」ところまで進めます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が、どの順で表示されるか」を予測します。とくに `g.label()` が、牛乳のときとパスタのときで結果が変わるかに注目してください。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week06/05_50m_ポリモーフィズム/PolyStockDemo.java` です。同じファイルに4つ書きます。抽象クラスが1つ、子クラスが2つ、実行用クラスが1つです。

```java
public class PolyStockDemo {
    public static void main(String[] args) {
        Goods[] shelf = {
            new FreshGoods("牛乳"),
            new DryGoods("パスタ"),
            new FreshGoods("レタス")
        };

        for (Goods g : shelf) {
            System.out.println(g.getName() + " → " + g.label());
        }
    }
}

abstract class Goods {
    String name;

    Goods(String name) {
        this.name = name;
    }

    String getName() {
        return name;
    }

    abstract String label();
}

class FreshGoods extends Goods {
    FreshGoods(String name) {
        super(name);
    }

    @Override
    String label() {
        return "要冷蔵";
    }
}

class DryGoods extends Goods {
    DryGoods(String name) {
        super(name);
    }

    @Override
    String label() {
        return "常温保存";
    }
}
```

実行は `java src/main/java/com/example/week06/05_50m_ポリモーフィズム/PolyStockDemo.java` です。
