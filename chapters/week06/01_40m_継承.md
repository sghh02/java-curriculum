# Week 6 継承（親の機能を引き継ぐ）

ここから OOP の後半です。今日は継承です。あるクラスの機能を、別のクラスがそのまま引き継ぎます。同じコードを何度も書かずに済みます。

## まず押さえること

継承は `extends` で書きます。`class 子 extends 親` とすると、子クラスは親のフィールドとメソッドをそのまま使えます。

```
class Employee {
    String name;
    void showName() { ... }
}

class Manager extends Employee {   // Employee を引き継ぐ
    void showRole() { ... }        // 子で足した機能
}
```

`Manager` は `name` と `showName` を書いていません。でも `Employee` から受け継ぐので使えます。そのうえで、子は自分だけの機能（`showRole`）を足せます。

親はもとになるクラスです。子はそこへ機能を足したクラスです。共通部分を親にまとめ、違いだけを子に書きます。

子から親を指す `super` という書き方もあります。親のメソッドを呼ぶなら `super.showName()` の形です。親のコンストラクタを呼ぶなら `super(値)` の形です。今回のお手本では使いません。あとの回で出てくるので、名前だけ覚えておいてください。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が、どの順で表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week06/01_40m_継承/EmployeeDemo.java` にします。同じファイルに3つのクラスを書きます。

```java
public class EmployeeDemo {
    public static void main(String[] args) {
        Manager m = new Manager();
        m.name = "田中";
        m.showName();
        m.showRole();
    }
}

class Employee {
    String name;

    void showName() {
        System.out.println("名前: " + name);
    }
}

class Manager extends Employee {
    void showRole() {
        System.out.println("役職: マネージャー");
    }
}
```

実行は `java src/main/java/com/example/week06/01_40m_継承/EmployeeDemo.java` です。

お手本のコードは閉じます。次の設計メモだけを手がかりに、`EmployeeDemo` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

  - フィールド … name（String）
