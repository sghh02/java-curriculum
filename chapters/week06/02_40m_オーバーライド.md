# Week 6 オーバーライド（親のメソッドを上書きする）

継承の続きです。前回は親のメソッドを「そのまま」使いました。今回は、子が親と同じ名前のメソッドを書き直します。これをオーバーライドと呼びます。共通の呼び名（メソッド名）はそのままに、中身だけ子ごとに変えられます。

## まず押さえること

子クラスで、親と同じ名前・同じ引数のメソッドを書くと、子のほうが優先されます。親の中身は上書きされて、子の中身が使われます。

```
class Shape {
    void draw() { System.out.println("描きます"); }
}

class Circle extends Shape {
    @Override
    void draw() { System.out.println("まるく描きます"); }   // 上書き
}
```

`Circle` の `draw()` を呼ぶと、親の「描きます」ではなく子の「まるく描きます」が出ます。

`@Override` は「これは親のメソッドを上書きしています」という目印です。書いておくと、名前を打ち間違えて上書きになっていないとき、コンパイラが教えてくれます。安全のために付けます。

フィールドは前回どおり継承されます。上書きするのはメソッドの中身だけです。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が表示されるか」を予測します。親の `draw` と子の `draw` の、どちらが呼ばれるかに注目してください。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week06/02_40m_オーバーライド/ShapeDemo.java` です。同じファイルに3つのクラスを書きます。

```java
public class ShapeDemo {
    public static void main(String[] args) {
        Circle c = new Circle();
        c.name = "円";
        c.draw();
    }
}

class Shape {
    String name;

    void draw() {
        System.out.println(name + "を描きます");
    }
}

class Circle extends Shape {
    @Override
    void draw() {
        System.out.println(name + "をまるく描きます");
    }
}
```

実行は `java src/main/java/com/example/week06/02_40m_オーバーライド/ShapeDemo.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`ShapeDemo` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- `Shape` クラス（親）
  - フィールド … name（String）
  - `draw()` … `円を描きます` のように name を表示する
- `Circle` クラス（子、`Shape` を継承）
  - `draw()` … 親の `draw` をオーバーライドする。`円をまるく描きます` と表示する。`@Override` を付ける
- 実行用クラス `ShapeDemo`
  - `main` で Circle を作り、name に "円" を入れる
  - `draw()` を呼ぶ
