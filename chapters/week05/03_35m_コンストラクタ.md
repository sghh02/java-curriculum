# Week 5 コンストラクタ（作る瞬間に初期化する）

これまでは実体を作ってから、フィールドに1つずつ値を入れていました。今日は実体を作る瞬間に、まとめて値を入れます。この仕組みをコンストラクタと呼びます。

## まず押さえること

コンストラクタは、`new` で実体を作るときに動く特別なメソッドです。名前はクラス名と同じにします。戻り値の型は書きません。

```
class Movie {
    String title;
    int year;

    Movie(String title, int year) {   // コンストラクタ
        this.title = title;
        this.year = year;
    }
}
```

`new Movie("となりのトトロ", 1988)` と書くと、このコンストラクタが動きます。渡した2つの値が、そのまま実体のフィールドに入ります。1行ずつ代入する手間が消えます。

ここで `this` が出てきます。`this` は「今まさに作っている実体自身」を指します。`this.title` は実体のフィールド、右側の `title` は引数です。名前が同じでも、`this` を付けるとフィールドのほうだと区別できます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week05/03_35m_コンストラクタ/MovieDemo.java` にします。同じファイルに2つのクラスを書きます。

```java
public class MovieDemo {
    public static void main(String[] args) {
        Movie movie = new Movie("となりのトトロ", 1988);
        movie.show();
    }
}

class Movie {
    String title;
    int year;

    Movie(String title, int year) {
        this.title = title;
        this.year = year;
    }

    void show() {
        System.out.println(title + "（" + year + "年）");
    }
}
```

実行は `java src/main/java/com/example/week05/03_35m_コンストラクタ/MovieDemo.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`MovieDemo` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `MovieDemo`
  - `main` で `new Movie("となりのトトロ", 1988)` を作り、`show()` を呼ぶ
- `Movie` クラス
  - フィールド … title（String）、year（int）
  - コンストラクタ … title と year を受け取り、`this` でフィールドに入れる
  - `show()` … `◯（◯年）` の形で title と year を表示する
