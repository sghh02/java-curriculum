# Week 5 値渡し（引数を渡すと何が渡るのか）

前回はオーバーロードを見ました。今回は引数の渡り方です。メソッドへ変数を渡したとき、呼び出し元の変数はどうなるのか。ここを勘違いすると、原因の分かりにくいバグになります。

Java の渡し方は1種類だけです。値渡しと呼びます。ただし、渡している値の中身が型によって違います。

## まず押さえること

`int` のような基本の型では、値そのものが写されます。

```
static void change(int n) {
    n = 99;      // 写しを書き換えているだけ
}
```

呼び出し元の変数は変わりません。渡した時点で別物になっているからです。

いっぽう、クラスから作った実体では、置き場所を指す札が写されます。

```
static void change(Box box) {
    box.value = 99;   // 同じ実体をさわる
}
```

札の写しでも、指している先は同じ実体です。だからフィールドを書き換えると、呼び出し元にも伝わります。

引数そのものへ新しい実体を代入した場合は違います。

```
static void change(Box box) {
    box = new Box();  // 写しの札を差し替えただけ
}
```

呼び出し元の札は元のままです。だから何も変わりません。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week05/07_40m_値渡し/PassByDemo.java` です。

```java
public class PassByDemo {
    static void changeNumber(int n) {
        n = 99;
    }

    static void changeField(Box box) {
        box.value = 99;
    }

    static void changeBox(Box box) {
        box = new Box();
    }

    public static void main(String[] args) {
        int num = 1;
        changeNumber(num);
        System.out.println("int: " + num);

        Box b = new Box();
        changeField(b);
        System.out.println("フィールド: " + b.value);

        changeBox(b);
        System.out.println("入れ替え: " + b.value);
    }
}

class Box {
    int value = 1;
}
```

実行は `java src/main/java/com/example/week05/07_40m_値渡し/PassByDemo.java` です。

写しながら、次を自分に問いかけてください。

- `changeNumber` のあと、num は 1 と 99 のどちらか
- `changeField` のあと、b.value はいくつか
- `changeBox` のあと、b.value は元へ戻るか
- 3つのうち、呼び出し元へ影響するのはどれか

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`PassByDemo` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `PassByDemo`
- クラス `Box` … `int value` を1つ持ち、1 で初期化する
- `changeNumber` … `int n` を受け取り、99 を代入する。戻り値なし
- `changeField` … `Box box` を受け取り、そのフィールドへ 99 を代入する。戻り値なし
- `changeBox` … `Box box` を受け取り、引数へ新しい `Box` を代入する。戻り値なし
- 3つとも `static` を付ける
- main の1つめ … `int num` に 1 を入れて `changeNumber` へ渡す。そのあと num を `int: ◯` の形で表示
- main の2つめ … `Box b` を作って `changeField` へ渡す。そのあと b のフィールドを `フィールド: ◯` の形で表示
- main の3つめ … 同じ b を `changeBox` へ渡す。そのあと b のフィールドを `入れ替え: ◯` の形で表示
