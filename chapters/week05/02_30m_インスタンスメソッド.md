# Week 5 インスタンスメソッド（クラスに振る舞いを持たせる）

前回はクラスにフィールド（値）を持たせました。今日はクラスにメソッド（振る舞い）を持たせます。実体が自分のフィールドを使って動きます。

## まず押さえること

クラスの中にはフィールドだけでなく、メソッドも書けます。このメソッドは、その実体が持つフィールドを使えます。

```
class Dog {
    String name;          // フィールド

    void bark() {         // メソッド
        System.out.println(name + "はワンワン");
    }
}
```

呼ぶときは `実体.メソッド名()` の形です。`dog.bark()` のように、どの実体の振る舞いかを指定します。

このメソッドには `static` を付けません。理由は、`name` という実体ごとに変わる値を使うからです。実体を指定して呼ぶので、その実体の `name` を読めます。以前 `add` に `static` を付けたのは、実体の値を使わなかったからです。ここが使い分けです。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week05/02_30m_インスタンスメソッド/DogDemo.java` にします。同じファイルに2つのクラスを書きます。

```java
public class DogDemo {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.name = "ポチ";
        dog.bark();
    }
}

class Dog {
    String name;

    void bark() {
        System.out.println(name + "はワンワン");
    }
}
```

実行は `java src/main/java/com/example/week05/02_30m_インスタンスメソッド/DogDemo.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`DogDemo` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `DogDemo`
  - `main` で `new Dog()` を作る
  - 実体の name に `ポチ` を入れ、`bark()` を呼ぶ
- `Dog` クラス
  - フィールド … name（String）
  - `bark()` … `static` を付けない。`◯はワンワン` の形で name を表示する

新しいファイル `src/main/java/com/example/week05/02_30m_インスタンスメソッド/CatDemo.java` を作ります。これまでのファイルは直しません。

テーマは「猫が自己紹介する」です。次のとおり書いてください。

- `Cat` クラスを作る。フィールドは name（String）と age（int）
- `Cat` に `introduce` というメソッドを作る。`static` は付けない
- `introduce` は `タマは3歳です` のように、name と age を使って1行表示する
- `main` で Cat の実体を作り、フィールドに "タマ" と 3 を設定して `introduce` を呼ぶ

実行用のクラス名は `CatDemo` にします。書けたら回答を `submissions/week05/02_30m_インスタンスメソッド.md` に貼り、「レビューして」と言ってください。
