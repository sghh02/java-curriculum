# Week 5 オーバーロード（同じ名前で引数違いのメソッド）

前回は `static` を見ました。今回はメソッドの名前の付け方です。同じ名前のメソッドを、引数の形を変えて何個も作れます。オーバーロードと呼びます。

`System.out.println` がその代表です。数値と文字列を同じ名前で渡せます。中身は引数の型ごとに別々のメソッドです。標準ライブラリを読むときの基礎知識になります。

## まず押さえること

同じ名前でも、引数の形が違えば別のメソッドとして扱われます。

```
static int add(int a, int b)
static double add(double a, double b)
static int add(int a, int b, int c)
```

渡した引数の形を見て、Java が使うものを選びます。`add(3, 4)` なら1つめ、`add(1.5, 2.5)` なら2つめです。

区別に使えるのは引数の形だけです。次の2つは作れません。

- 引数がまったく同じで、戻り値の型だけ違うもの
- 引数がまったく同じで、引数の名前だけ違うもの

どちらも呼び出し側から区別できないからです。

似た処理に別々の名前を付けると、使う側の覚えることが増えます。同じ意味の処理は同じ名前にそろえる。これがオーバーロードのねらいです。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week05/06_35m_メソッドのオーバーロード/OverloadDemo.java` です。

```java
public class OverloadDemo {
    static int add(int a, int b) {
        return a + b;
    }

    static double add(double a, double b) {
        return a + b;
    }

    static int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        System.out.println("int 2つ: " + add(3, 4));
        System.out.println("double 2つ: " + add(1.5, 2.5));
        System.out.println("int 3つ: " + add(1, 2, 3));
    }
}
```

実行は `java src/main/java/com/example/week05/06_35m_メソッドのオーバーロード/OverloadDemo.java` です。

写しながら、次を自分に問いかけてください。

- `add(3, 4)` はどの `add` を呼ぶか
- `add(1.5, 2.5)` の答えは 4 と 4.0 のどちらで出るか
- 3つの `add` は、どこで区別されているか
- 引数を1つだけにした `add` を足せるか
