# Week 5 クラスとインスタンス（設計図から実体を作る）

ここから Phase 2 の OOP です。今日はクラスを自分で定義し、`new` で実体を作って使います。先日話した `new` を実際に手で書きます。

## まず押さえること

クラスは、データのまとまりに名前を付けた設計図です。たとえば「人」なら、名前と年齢をひとまとめにできます。

クラスが持つ値をフィールドと呼びます。フィールドは、クラスの中に書いた変数です。

設計図から実体を作るのが `new` です。`new クラス名()` と書くと、実体が1つできます。この実体をインスタンスと呼びます。

```
クラス名 変数 = new クラス名();   // 実体を1つ作る
変数.フィールド = 値;             // フィールドに値を入れる
```

実体ごとに、それぞれのフィールドを持ちます。太郎の実体と花子の実体は、別々の名前と年齢を持てます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「何が、どの順で表示されるか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week05/01_30m_クラスとインスタンス/PersonDemo.java` にします。同じファイルに2つのクラスを書きます。

```java
public class PersonDemo {
    public static void main(String[] args) {
        Person p = new Person();
        p.name = "太郎";
        p.age = 20;
        System.out.println(p.name + "は" + p.age + "歳です");
    }
}

class Person {
    String name;
    int age;
}
```

実行は `java src/main/java/com/example/week05/01_30m_クラスとインスタンス/PersonDemo.java` です。
