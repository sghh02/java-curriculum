## パート1: お手本を読む

次のコードを、上から1行ずつ読みます。1行ごとに「この行は何をするか」を自分の言葉で言ってからつぎへ進みます。まだ実行しません。

```java
public class Hello {
    public static void main(String[] args) {
        String name = "Java";
        int day = 1;
        System.out.println("Hello, " + name);
        System.out.println("Day " + day);
    }
}
```

問い: 6行それぞれが何をする行か、言葉で説明してください。

## パート2: 出力を予測する（トレース問題）

次の3つを実行すると、コンソールに何が表示されるかを予測します。実行する前に、紙かメモに答えを書き出してください。

問1

```java
System.out.println("合計: " + 1 + 2);
```

問2

```java
System.out.println(1 + 2 + " 点");
```

問3

```java
String name = "Java";
int day = 1;
System.out.println(name + " Day " + day);
```

予測を書き終えたら、実際に動かして答え合わせします。
