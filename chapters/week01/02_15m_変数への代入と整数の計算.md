# Week 1 「読む・予測する」訓練その2

テーマは、変数への代入と整数の計算です。コードはまだ書きません。読んで予測します。

## パート1: お手本を読む

上から1行ずつ読み、その行が何をするかを自分の言葉で言ってから次へ進みます。まだ実行しません。

```java
public class Calc {
    public static void main(String[] args) {
        int a = 10;
        int b = 3;
        int sum = a + b;
        System.out.println("sum = " + sum);
        a = a + 5;
        System.out.println("a = " + a);
    }
}
```

問い: `a = a + 5;` の行は何をしていますか。言葉で説明してください。

## パート2: 出力を予測する（トレース問題）

次の4つを実行すると、コンソールに何が表示されるかを予測します。実行する前に、メモへ書き出してください。

問1

```java
System.out.println(7 / 2);
```

問2

```java
System.out.println(7 % 2);
```

問3

```java
int x = 4;
x = x + 1;
x = x * 2;
System.out.println(x);
```

問4

```java
System.out.println("結果: " + 3 + 4);
```

予測を書き終えたら、実際に動かして答え合わせします。
