# Week 1 「読む・予測する」訓練その3

テーマは、比較（true と false）と `if` 文です。コードはまだ書きません。読んで予測します。

## パート1: お手本を読む

上から1行ずつ読み、その行が何をするかを自分の言葉で言ってから次へ進みます。まだ実行しません。

```java
public class Judge {
    public static void main(String[] args) {
        int score = 72;
        if (score >= 60) {
            System.out.println("合格");
        } else {
            System.out.println("不合格");
        }
    }
}
```

問い: `if (score >= 60)` の行は何を判断していますか。このコードは何を表示しますか。

## パート2: 出力を予測する（トレース問題）

次の4つを実行すると、コンソールに何が表示されるかを予測します。実行する前に、メモへ書き出してください。

問1

```java
System.out.println(5 > 3);
```

問2

```java
int n = 10;
System.out.println(n == 10);
```

問3

```java
int age = 18;
if (age >= 20) {
    System.out.println("大人");
} else {
    System.out.println("未成年");
}
```

問4

```java
int x = 60;
if (x > 60) {
    System.out.println("A");
} else {
    System.out.println("B");
}
```

予測を書き終えたら、実際に動かして答え合わせします。
