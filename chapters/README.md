# problems

Claude Code が出題した問題を置くフォルダです。1回の出題が1ファイルです。

## フォルダ

Week ごとに分かれています。

- `week01/` … 読む訓練
- `week02/` … 変数と型
- `week03/` … 制御構文
- `week04/` … メソッド・コレクション・例外
- `week05/` … クラス
- `week06/` … OOP 後半
- `week07/` … 内部APIの基礎

どの回が完了で、どの回が対象外かは [PROGRESS.md](../PROGRESS.md) にあります。

## ファイル名

`MM_時間_タイトル.md` の形です（例 `week06/01_40m_継承.md`）。

- `MM` … その Week での出題順を表す2桁の連番
- `時間` … 所要時間の見積もり。`40m` は40分
- `タイトル` … その回の内容を表す日本語

## ファイルの中身

どのファイルも、次の順で書かれています。

- まず押さえること … 今回の概念の説明
- ステップ1: 予測写経 … お手本の完成コード、保存先、実行コマンド
- ステップ2: 暗写 … 設計メモ。完成コードは載せない
- ステップ3: 自力 … 要件だけを示した小さな課題

## 対応するフォルダ

同じ Week フォルダの同じファイル名で、次の3か所と対応します。

- [answers/](../answers/README.md) … 模範解答
- [submissions/](../submissions/README.md) … 自分の回答とレビュー結果
- [src/](../src/README.md) … 実際に書いた Java のファイル。こちらはファイル名から `.md` を除いたフォルダになる
