# Week 2 変数その3（文字列を組み立てる）

テーマは変数の続きです。今回は文字列どうしをつないで、新しい文字列を変数に入れます。

## まず押さえること

数値だけでなく、文字列も計算のように組み立てられます。`+` で文字列をつなぎ、結果を別の変数に入れられます。

```
String fullName = last + " " + first;
```

これは「last と空白と first をつないで、String の箱 fullName に入れる」という意味です。数値のときと形は同じで、結果を変数にためて後で使えます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。1行写すごとに「この行は何をするか」を予測してから写します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week02/03_20m_文字列の連結/Greeting.java` にします。

```java
public class Greeting {
    public static void main(String[] args) {
        String name = "Sato";
        String message = "こんにちは、" + name + "さん";
        System.out.println(message);
    }
}
```

実行は `java src/main/java/com/example/week02/03_20m_文字列の連結/Greeting.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Greeting` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `Greeting`
- `String name` … `Sato` を入れる
- `String message` … `こんにちは、`、name、`さん` をこの順でつないだ文字列を入れる
- `message` を表示する

## ステップ3: 自力

新しいファイル `src/main/java/com/example/week02/03_20m_文字列の連結/Card.java` を作ります。これまでのファイルは直しません。

テーマは「自己紹介カード」です。次のとおり組み立ててください。

- 名字 … 文字列。値は自由（例 "田中"）
- 名前 … 文字列。値は自由（例 "太郎"）
- フルネーム … 名字と名前をつないだ文字列を入れる（間に空白を1つ入れる）
- 年齢 … 整数。値は自由（例 20）
- 紹介文 … フルネームと年齢をつないだ文字列を入れる（例 "田中 太郎（20歳）"）

紹介文の1行だけを表示してください。クラス名は `Card` にします。書けたら回答を `submissions/week02/03_20m_文字列の連結.md` に貼り、「レビューして」と言ってください。
