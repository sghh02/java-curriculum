# Week 2 var（型を書かない変数宣言）

前回はラッパークラスを見ました。今回は変数の書き方です。`var` と書くと、型を省けます。右辺から型が決まるからです。現場のコードでよく見かけます。長い型名をくり返さずに済むためです。

ただし万能ではありません。使える場所と使えない場所があります。

## まず押さえること

これまでは型を先に書いていました。

```
String name = "Java";
int version = 21;
```

`var` を使うと、こう書けます。

```
var name = "Java";   // String になる
var version = 21;    // int になる
```

型が消えたわけではありません。右辺の値から Java が型を決めます。決まったあとは変えられません。`var version = 21;` のあとに文字列を入れるとエラーになります。

決まりが2つあります。

1つめは、宣言と同時に値を入れることです。`var x;` とだけ書くとエラーになります。型を決められないからです。

2つめは、`null` だけを入れられないことです。これも型が決まらないためです。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week02/11_30m_var/VarDemo.java` です。

```java
public class VarDemo {
    public static void main(String[] args) {
        var name = "Java";
        var version = 21;
        var ratio = 1.5;
        System.out.println(name + " / " + version + " / " + ratio);

        var message = name + " の文字数は " + name.length();
        System.out.println(message);

        var count = 0;
        count = count + 3;
        System.out.println("あとから代入: " + count);
    }
}
```

実行は `java src/main/java/com/example/week02/11_30m_var/VarDemo.java` です。

写しながら、次を自分に問いかけてください。

- `var name = "Java";` の型は何になるか
- `var ratio = 1.5;` は `int` と `double` のどちらになるか
- `name.length()` が呼べるのはなぜか
- `count` にあとから代入できるのはなぜか
