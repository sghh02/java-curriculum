# Week 2 ラッパークラス（int を包む型）

前回はキャストで型を移しました。今回は `int` を包む型の話です。`Integer` と書く型があります。実務では `int` より `Integer` を使う場面がよくあります。理由は空っぽの状態を持てるからです。

画面から送られてきた数値が未入力のとき、`int` では表しようがありません。`Integer` なら `null` を入れられます。

## まず押さえること

基本の型には、それぞれ対になる型があります。

```
int    → Integer
double → Double
boolean → Boolean
```

この対になる型をラッパークラスと呼びます。包むという意味です。

```
int a = 10;
Integer b = a;   // 包む
int c = b + 5;   // ほどいて計算する
```

包む作業とほどく作業は、Java が自動でやります。この自動の行き来をオートボクシングと呼びます。書き方は `int` とほとんど変わりません。

ここまでは `int` と `Integer` の似ているところです。違うところが2つあります。

1つめは `null` を入れられることです。`int` には必ず数が入ります。何も代入しなければ 0 です。「まだ値がない」と「値が 0 である」を区別できません。`Integer` なら `null` を入れられます。この2つを分けて表せます。

```
int x = 0;          // 0 という値
Integer y = null;   // 値がない
```

DB から取り出した列が空のときなどに効いてきます。0 と空を取り違えれば、集計がずれます。

2つめは、`Integer` が道具を持っていることです。`int` は型そのものなので、メソッドを付けられません。`Integer` はクラスです。だから便利な道具が最初から付いています。

```
Integer.parseInt("42")   // 文字列 "42" を数値 42 にする
```

`Integer.parseInt` は画面やファイルから受け取った文字を数値へ直すときに使います。現場で頻繁に出てきます。

保存先は `src/main/java/com/example/week02/10_35m_ラッパークラスとオートボクシング/WrapperDemo.java` です。

```java
public class WrapperDemo {
    public static void main(String[] args) {
        int a = 10;
        Integer b = a;
        System.out.println("int から Integer: " + b);
        System.out.println("そのまま計算できる: " + (b + 5));

        Integer empty = null;
        System.out.println("空を入れられる: " + empty);

        String text = "42";
        int num = Integer.parseInt(text);
        System.out.println("文字列から数値: " + (num + 1));
    }
}
```
