# Week 2 明示的キャスト（型を変えて値を移す）

前回は複数行の文字列を書きました。今回は数値の型を変える話です。`int` どうしの割り算は、小数を切り捨てます。この落とし穴は現場でもよく踏みます。平均や割合を出す計算で、答えが合わないときの原因になります。

## まず押さえること

`int` は整数、`double` は小数を持てる型でした。型が違うと、割り算の答えも変わります。

```
int total = 7;
int count = 2;
total / count           // 3。小数が切り捨てられる
(double) total / count  // 3.5
```

`(double)` のように、丸かっこで型名を書くとキャストになります。値を別の型へ移す指示です。

逆向きもできます。`(int)` を付けると小数が消えます。四捨五入ではなく切り捨てです。

小さい型へ移すときは注意が要ります。値が入りきらないと、まったく違う数になります。`byte` は -128 から 127 までしか持てません。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week02/09_30m_明示的キャスト/CastDemo.java` です。

```java
public class CastDemo {
    public static void main(String[] args) {
        int total = 7;
        int count = 2;
        System.out.println("int のまま割る: " + (total / count));
        System.out.println("キャストして割る: " + ((double) total / count));

        double price = 199.8;
        int cut = (int) price;
        System.out.println("double を int にする: " + cut);

        int big = 300;
        byte small = (byte) big;
        System.out.println("byte へ押し込む: " + small);
    }
}
```

実行は `java src/main/java/com/example/week02/09_30m_明示的キャスト/CastDemo.java` です。

写しながら、次を自分に問いかけてください。

- `total / count` の答えは 3.5 になるか
- `(double) total / count` で、キャストが効いているのはどちらの変数か
- `(int) 199.8` は 200 と 199 のどちらになるか
- `byte` へ 300 を押し込むと何が起きるか
