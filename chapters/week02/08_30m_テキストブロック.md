# Week 2 テキストブロック（複数行の文字列をそのまま書く）

前回までで `String` の比べ方まで進みました。今回は複数行の文字列です。これまでは `println` を並べるしかありませんでした。テキストブロックを使うと、見たままの形で書けます。

SQL を Java の中に書く場面で効いてきます。Phase 3 で必ず使う道具です。

## まず押さえること

改行は `\n` で表せます。1つの文字列の中に、2行分を入れられます。

```
String s = "1行目\n2行目";
```

ただし行が増えると読みにくくなります。そこでテキストブロックです。二重引用符3つで囲みます。

```
String s = """
        1行目
        2行目
        """;
```

決まりが3つあります。

1つめは、開きの `"""` のうしろで必ず改行することです。同じ行に文字は書けません。

2つめは、閉じの `"""` の位置が左端の基準になることです。行頭の空白は、その位置まで自動で削られます。だから字下げをそろえて書けます。

3つめは、閉じの `"""` を次の行に置くと、最後に改行が入ることです。改行を入れたくないときは、文字のすぐうしろで閉じます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。写す前に「この行は何をするか」を予測します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week02/08_30m_テキストブロック/NoticeText.java` です。

```java
public class NoticeText {
    public static void main(String[] args) {
        String oneLine = "お知らせ\n本日は休業します。";
        System.out.println(oneLine);
        System.out.println("----");

        String block = """
                お知らせ
                本日は休業します。
                担当: 山田
                """;
        System.out.print(block);
        System.out.println("----");

        String tight = """
                改行なしで終わる""";
        System.out.println(tight + "|");
    }
}
```

実行は `java src/main/java/com/example/week02/08_30m_テキストブロック/NoticeText.java` です。

`block` だけ `print` を使っています。`println` ではありません。理由を考えながら写してください。

写しながら、次を自分に問いかけてください。

- `oneLine` は何行になって出るか
- `block` の行頭の空白は、そのまま表示されるか
- `block` のあとの `----` は、どこへ出るか
- `tight` のうしろの `|` は、次の行へ回るかどうか

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`NoticeText` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `NoticeText`
- `String oneLine` … `\n` を使い、お知らせと休業の連絡を1つの文字列にする
- `oneLine` を `println` で表示
- 区切りの `----` を表示
- `String block` … テキストブロックで3行。お知らせ、休業の連絡、担当者の名前
- 閉じの `"""` は次の行に置く。最後の改行を残すため
- `block` を `print` で表示
- 区切りの `----` を表示
- `String tight` … テキストブロックで1行。閉じの `"""` を文字のすぐうしろに置く
- `tight` のうしろへ `|` をつないで `println` で表示

## ステップ3: 自力

新しいファイル `src/main/java/com/example/week02/08_30m_テキストブロック/RecipeText.java` を作ります。これまでのファイルは直しません。

テーマは「レシピの表示」です。次のとおり書いてください。

- クラス名は `RecipeText` にする
- `String items` … `\n` を使い、`材料` と `卵 2個` を1つの文字列にする
- items を `println` で表示する
- 区切りとして `====` を表示する
- `String steps` … テキストブロックで作り方を3行。`1. 卵を割る`、`2. まぜる`、`3. 焼く`
- steps を `print` で表示する。最後の改行はテキストブロック側で持たせる
- ふたたび `====` を表示する
- `String tail` … 改行なしで終わるテキストブロック。中身は `できあがり`
- tail のうしろへ `|` をつないで `println` で表示する
