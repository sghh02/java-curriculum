# Week 2 変数その4（値を書き換える）

テーマは変数の続きです。今回は、一度入れた変数の値を、途中で書き換えます。

## まず押さえること

変数の値は、あとから入れ直せます。`=` は「右の値を左へ入れる」記号でした。だから同じ変数に、新しい値を入れ直せます。

```
int count = 0;
count = count + 1;
```

2行目は「今の count に 1 を足した結果を、count に入れ直す」という意味です。count は 0 から 1 になります。もとの値を使って、新しい値に更新できます。

## ステップ1: 予測写経

次のお手本を1行ずつ写します。1行写すごとに「この行のあと、変数はいくつになるか」を予測してから写します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week02/04_25m_値の書き換え/Counter.java` にします。

```java
public class Counter {
    public static void main(String[] args) {
        int count = 0;
        System.out.println("最初: " + count);
        count = count + 1;
        count = count + 1;
        count = count + 1;
        System.out.println("あと: " + count);
    }
}
```

実行は `java src/main/java/com/example/week02/04_25m_値の書き換え/Counter.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Counter` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `Counter`
- `int count` … 0 を入れる
- `最初: ◯` … count を表示する
- `count = count + 1;` を3回くり返す
- `あと: ◯` … 書き換えたあとの count を表示する

## ステップ3: 自力

新しいファイル `src/main/java/com/example/week02/04_25m_値の書き換え/Wallet.java` を作ります。これまでのファイルは直しません。

テーマは「財布の残高」です。次の順で書き換えてください。

- 残高 … 整数。最初は 1000 を入れる
- 500 をもらう（残高に 500 を足して入れ直す）
- 300 を使う（残高から 300 を引いて入れ直す）
- 最後に残高を1行表示する（例 `残高: 1200`）

クラス名は `Wallet` にします。書けたら回答を `submissions/week02/04_25m_値の書き換え.md` に貼り、「レビューして」と言ってください。

今回のポイントは、残高を直に 1200 と書かないことです。1000 から始めて、足す・引くで書き換えて 1200 を出してください。値を変えても正しく動く形にします。
