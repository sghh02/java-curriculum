# Week 2 変数その2（計算する）

テーマは変数の続きです。今回は変数どうしを計算し、結果を別の変数に入れます。

## まず押さえること

変数は計算に使えます。右側で計算した結果を、左の変数に入れられます。

```
int total = a + b;
```

これは「a と b を足した結果を、int の箱 total に入れる」という意味です。使える計算は次のとおりです。

- `+` 足す
- `-` 引く
- `*` かける
- `/` 割る（整数どうしは切り捨て）
- `%` 割ったあまり

## ステップ1: 予測写経

次のお手本を1行ずつ写します。1行写すごとに「この行は何をするか」を予測してから写します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week02/02_25m_変数どうしの計算/Cart.java` にします。

```java
public class Cart {
    public static void main(String[] args) {
        int price = 300;
        int count = 4;
        int total = price * count;
        System.out.println("単価: " + price);
        System.out.println("個数: " + count);
        System.out.println("合計: " + total);
    }
}
```

実行は `java src/main/java/com/example/week02/02_25m_変数どうしの計算/Cart.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Cart` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `Cart`
- `int price` … 300 を入れる
- `int count` … 4 を入れる
- `int total` … price と count をかけた結果を入れる
- `単価: ◯` `個数: ◯` `合計: ◯` の形で、3つを1行ずつ表示する

## ステップ3: 自力

`Profile` や `Cart` は直しません。新しいファイル `src/main/java/com/example/week02/02_25m_変数どうしの計算/Change.java` を作り、その中に書きます。

テーマは「おつり」です。次のとおり計算してください。

- 支払い … 整数。値は自由（例 1000）
- 代金 … 整数。値は自由（例 720）
- おつり … 支払いから代金を引いた結果を入れる

3つの変数を作り、ラベルをつけて3行表示してください（例 `おつり: 280`）。クラス名は `Change` にします。書けたら回答を `submissions/week02/02_25m_変数どうしの計算.md` に貼り、「レビューして」と言ってください。
