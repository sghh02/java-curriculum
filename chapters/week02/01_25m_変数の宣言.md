# Week 2 変数

テーマは変数です。今回から自分の手で書きます。読むだけの回は終わりです。

## まず押さえること

変数は「値を入れておく名前つきの箱」です。Java では、箱を作るときに何を入れる箱かを決めます。これを型と呼びます。

よく使う型は次の4つです。

- `int` … 整数（例 25）
- `double` … 小数（例 170.5）
- `String` … 文字列（例 "Sato"）
- `boolean` … true か false

書き方の形はこうです。

```
型 名前 = 値;
```

例えば `int age = 25;` は「int の箱 age を作り、25 を入れる」という意味です。

## ステップ1: 予測写経

次のお手本を、1行ずつ写します。1行写すごとに「この行は何をするか」を予測してから写します。写し終えたら実行し、予測と合っているか確かめます。

保存先は `src/main/java/com/example/week02/01_25m_変数の宣言/Profile.java` にします。

```java
public class Profile {
    public static void main(String[] args) {
        String name = "Sato";
        int age = 25;
        double height = 170.5;
        boolean student = false;
        System.out.println("名前: " + name);
        System.out.println("年齢: " + age);
        System.out.println("身長: " + height);
        System.out.println("学生: " + student);
    }
}
```

実行は `java src/main/java/com/example/week02/01_25m_変数の宣言/Profile.java` です。

## ステップ2: 暗写（設計メモから組み立てる）

お手本のコードは閉じます。次の設計メモだけを手がかりに、`Profile` を書きます。丸暗記ではなく、設計をコードへ起こす練習です。書けたら実行し、同じ出力になるか確かめます。

- 実行用クラス `Profile`
- `String name` … `Sato` を入れる
- `int age` … 25 を入れる
- `double height` … 170.5 を入れる
- `boolean student` … false を入れる
- `名前: ◯` `年齢: ◯` `身長: ◯` `学生: ◯` の形で、4つを1行ずつ表示する

## ステップ3: 自力

お手本なしで、少し違うプログラムを書きます。`Profile` は直しません。新しいファイル `src/main/java/com/example/week02/01_25m_変数の宣言/Book.java` を作り、その中に書きます。1つのファイルに `public class` は1つまでなので、別ファイルにします。

テーマは「本の情報」です。次の4つの変数を作り、それぞれを表示してください。

- タイトル … 文字列。値は自由（例 "Java入門"）
- 値段 … 整数。値は自由（例 2800）
- 評価 … 小数。値は自由（例 4.5）
- 在庫あり … true か false

表示はお手本と同じく `System.out.println` を使います。ラベルをつけて4行出してください（例 `タイトル: Java入門`）。
